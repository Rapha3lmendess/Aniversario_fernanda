# 💙 Nosso Universo

Um site romântico e interativo criado como um presente especial para guardar lembranças, mensagens e momentos inesquecíveis.

## ✨ Funcionalidades

- 🌌 Entrada cinematográfica com animações.
- 💌 História, fotos, cartas e surpresas.
- 🎮 Área dedicada ao Roblox.
- 🧩 Quiz e caça-palavras interativos.
- 🎵 Trilha sonora personalizada.
- 🌗 Tema claro e escuro.
- 🎂 Mural de aniversário com mensagens dos amigos.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase
